# Operating System v0 — Mati y Ali Rugs

Este documento define cómo usar Mati y Ali Rugs como negocio real y, al mismo tiempo, como laboratorio para construir sistemas reutilizables de MatiOS.

## Principio central

Empezar manual y imperfecto. Medir. Detectar qué funciona. Convertirlo en proceso. Recién después automatizarlo.

Secuencia:

1. Hacer manualmente.
2. Registrar qué pasos se repiten.
3. Probar scripts, librerías, prompts, skills y herramientas.
4. Comparar resultados.
5. Elegir el flujo que mejor funciona.
6. Convertirlo en template/SOP.
7. Automatizar solo lo estable.
8. Medir y volver a iterar.

No construir una "fábrica teórica" antes de tener producción, clientes y contenido reales.

## Tres sistemas desde el día uno

### 1. Producción
Objetivo: aprender a fabricar una pieza bien y repetirla.

Registrar por alfombra:
- diseño y versión;
- medidas;
- dificultad;
- cantidad de colores;
- tipo/lote de hilo;
- gramos usados;
- desperdicio;
- panamá, adhesivo y backing;
- tiempo de trazado;
- tiempo de tufting;
- tiempo de carving/esquilado;
- tiempo de terminación;
- errores y retrabajo;
- costo real;
- fotos de frente, reverso, bordes y detalle;
- qué salió bien / qué cambiar para la próxima.

Crear una escala de dificultad para que tamaño + colores + detalle + curvas + carving + relieve alimenten pricing y capacidad.

### 2. Comercial
Objetivo: aprender a convertir interés en pedidos sin fricción.

Flujo inicial:
lead → conversación → brief → referencia/foto → propuesta → correcciones → aprobación → presupuesto → seña → producción → avances → saldo → entrega → postventa → reseña/foto final.

Cada pedido real debe servir para construir:
- plantillas de WhatsApp;
- preguntas de brief;
- políticas de cambios;
- reglas de aprobación;
- calculadora de costos/precio;
- CRM;
- seguimiento de estados;
- base de proveedores;
- aprendizaje de objeciones y motivos de compra.

### 3. Contenido / Content Factory
Objetivo: hacer que cada etapa del negocio genere material.

Flujo inicial:
capturar → ordenar → seleccionar historia → elegir hook → editar → subtitular → publicar → medir → aprender → repetir.

Al principio puede ser completamente manual. Mati puede correr scripts, probar librerías, herramientas y skills una por una. Cuando un flujo produzca resultados consistentes, recién ahí se transforma en automatización reutilizable.

El contenido no requiere siempre edición compleja. Muchas piezas pueden funcionar con:
- buena selección de clips;
- ritmo;
- subtítulos;
- hook claro;
- música/sonido simple;
- contexto y cierre.

Usar Mati y Ali Rugs como cliente cero de la Content Factory.

## Qué filmar desde el día uno

Antes de cada actividad pensar dos preguntas:
1. ¿Qué necesitamos registrar para aprender/operar mejor?
2. ¿Qué parte de esto puede convertirse en contenido?

Capturar especialmente momentos irrepetibles:
- primeras reacciones;
- primer contacto con herramientas;
- errores espontáneos;
- decisiones reales;
- primera pieza;
- primera venta;
- primera entrega;
- reacción del cliente;
- evolución pieza #1 vs pieza #10.

Los planos técnicos, explicaciones, capturas de pantalla y voces en off pueden recrearse después.

## Control de calidad visible

Crear un protocolo fotográfico estándar por pieza:
- foto completa frontal;
- foto del reverso;
- bordes;
- carving/detalle;
- escala con referencia;
- foto instalada en ambiente si es posible.

Esto sirve para QA, evolución técnica, catálogo y contenido.

## Biblioteca de diseños

Cada diseño aprobado debe transformarse en activo digital con:
- master original;
- versión tufting-ready;
- paleta;
- mockup;
- tamaño mínimo recomendado;
- dificultad;
- consumo estimado;
- horas estimadas;
- versión final producida;
- aprendizajes.

Con el tiempo, los pedidos custom alimentan el catálogo.

## Proveedores y continuidad

Para insumos críticos intentar tener al menos dos opciones:
- hilo;
- panamá;
- adhesivo;
- backing;
- repuestos de gun;
- herramientas.

Registrar proveedor, precio, fecha, lote, calidad, lead time y observaciones.

## Capacidad de Ali

La capacidad no se mide solo en piezas/mes. También medir:
- horas reales;
- fatiga;
- tareas que disfruta;
- tareas repetitivas que pueden delegarse;
- calidad cuando aumenta el volumen.

El crecimiento no debe destruir el carácter artesanal ni convertir el proyecto en una carga.

## Packaging y entrega

Diseñar una experiencia simple pero cuidada:
- protección correcta;
- tarjeta de cuidados;
- nombre/modelo de la pieza;
- posible número de serie en piezas especiales;
- firma o sello de Ali;
- instrucciones de mantenimiento.

La entrega también debe generar contenido cuando el cliente lo autorice.

## Postventa

A los 7–15 días:
- preguntar cómo quedó;
- pedir foto instalada;
- pedir reseña;
- detectar problemas;
- solicitar permiso para publicar.

Cada venta debería terminar produciendo feedback, prueba social y datos.

## Propiedad intelectual y permisos

Clasificar diseños como:
- propio;
- creado desde material del cliente;
- fan art / referencia cultural;
- marca/logo protegido;
- licencia incierta.

No asumir que algo visible en marketplaces está autorizado.

## Biblioteca de viabilidad

Guardar ejemplos de:
- diseño viable tal cual;
- diseño que requiere simplificación;
- diseño que requiere mayor tamaño;
- diseño que conviene rechazar.

Esto puede alimentar más adelante al asistente de presupuestos/diseño.

## Temporadas y campañas

No producir stock por adelantado al inicio. Sí preparar conceptos y contenido para:
- Día de la Madre;
- Navidad;
- cumpleaños;
- aniversarios;
- mascotas;
- mudanzas/decoración;
- regalos personalizados.

## Pieza viral vs producto rentable

Separar dos criterios:
- potencial visual/viral;
- rentabilidad/repetibilidad.

Una pieza espectacular puede servir como contenido y portfolio aunque no sea la mejor SKU para volumen.

## Backlog de experimentos

Guardar ideas sin ejecutarlas todas a la vez:
- relieve 3D;
- degradés;
- lana natural;
- otras fibras;
- alfombra de baño;
- formas orgánicas;
- piezas de pared;
- tamaños grandes;
- nuevos acabados.

Probar un experimento por vez y medir.

## Regla de automatización

Automatizar solo cuando exista:
- un proceso real;
- repetición suficiente;
- criterio de éxito;
- datos para comparar antes/después.

Ejemplos de camino manual → sistema:
- edición manual → preset/template → script → skill → pipeline;
- cotización manual → planilla → calculadora → asistente;
- WhatsApp manual → templates → CRM → agente;
- organización de clips manual → naming/folders → metadata → pipeline de Content Factory.

## Resultado buscado

Mati y Ali Rugs no es solamente una marca artesanal. Es un entorno real donde MatiOS puede aprender a operar producción física, ventas, contenido, proveedores, pricing, CRM y automatización con human-in-the-loop.

La prioridad inicial es que el negocio funcione aunque el flujo sea imperfecto. Después se moderniza, modulariza y automatiza lo que demuestre valor.
