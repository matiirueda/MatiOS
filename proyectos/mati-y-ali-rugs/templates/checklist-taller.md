# Checklist para el taller de tufting

Objetivo: salir del curso con datos suficientes para decidir compra de equipamiento y estimar la economía real del negocio.

## Técnica

- [ ] Modelo exacto de tufting gun usada.
- [ ] Cut pile / loop pile / duo.
- [ ] Cómo tensan la tela y qué bastidor recomiendan.
- [ ] Tipo de tela primaria.
- [ ] Tipo/grosor/título de hilo y cantidad de cabos.
- [ ] Densidad recomendada.
- [ ] Orden óptimo: contornos, colores, relleno.
- [ ] Errores frecuentes y cómo corregirlos.
- [ ] Adhesivo usado, cantidad y tiempo de secado.
- [ ] Backing usado.
- [ ] Esquiladora/carving: modelo, técnica y repuestos.
- [ ] Cómo resolver bordes y curvas.
- [ ] Limpieza y mantenimiento de una alfombra terminada.

## Costos y consumo

- [ ] Peso de hilo inicial por color.
- [ ] Peso sobrante por color.
- [ ] Consumo real total de la pieza 50x50.
- [ ] Desperdicio aproximado.
- [ ] Coste de tela.
- [ ] Coste de hilo.
- [ ] Coste de adhesivo.
- [ ] Coste de backing.
- [ ] Coste total de consumibles.

## Tiempo

Registrar minutos reales por etapa:

- diseño/adaptación;
- trazado;
- tufting;
- pegado;
- secado (no mano de obra);
- corte inicial;
- esquilado;
- carving;
- backing;
- terminación/embalaje.

## Proveedores y equipamiento

- [ ] Proveedores de tela.
- [ ] Proveedores de hilo/lana.
- [ ] Proveedores de adhesivo/backing.
- [ ] Máquina que comprarían para producción diaria.
- [ ] Repuestos críticos.
- [ ] Qué evitar de máquinas baratas.
- [ ] Si conviene importar China y qué especificaciones exigir.

## Negocio

- [ ] Cómo presupuestan personalizados.
- [ ] Cuánto agregan por complejidad.
- [ ] Plazos habituales.
- [ ] Tamaño máximo práctico para una persona.
- [ ] Cuántas piezas puede producir una persona por semana.
- [ ] Problemas habituales de clientes/devoluciones.

## Resultado del experimento

Al terminar completar:

- ¿A Ali le gustó la actividad?
- ¿La técnica le resultó natural?
- ¿Matías puede cubrir producción en caso de necesidad?
- ¿Calidad de la primera pieza del 1 al 10?
- ¿Qué compraríamos distinto después de probar?
- Decisión: GO / REPETIR PRUEBA / NO-GO.
