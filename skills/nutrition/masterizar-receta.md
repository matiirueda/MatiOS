# Skill — Masterizar receta

## Propósito
Conservar una receta original y generar una adaptación específica para los objetivos de Mati sin destruir la fuente.

## Flujo
1. Extraer la receta original fielmente.
2. Guardar fuente e imagen si existen.
3. Identificar función: desayuno, snack, post-entreno, comida principal, etc.
4. Evaluar proteína, carbohidratos, grasas, fibra y micronutrientes.
5. Consultar preferencias personales.
6. Aplicar boosters solo cuando aporten valor.
7. Aplicar el principio de invisibilidad nutricional.
8. Crear una versión Growth cuando corresponda.
9. Mantener una versión Fit solo si agrega valor real.
10. Estimar macros y marcar supuestos.
11. Dejar el puntaje Mati pendiente hasta probar.
12. Nunca sobrescribir la receta original.

## Puntaje Mati

```yaml
matias_score:
  status: pending
  taste:
  ease:
  cost:
  satiety:
  would_repeat:
  notes:
```

## Regla
La optimización nutricional no puede empeorar sustancialmente sabor, textura ni adherencia.
