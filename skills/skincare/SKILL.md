# Skincare Skill

## Propósito
Aplicar la rutina dermatológica vigente sin depender de memoria conversacional.

## Fuente principal
`cerebro/salud/dermatologia-skincare.md`

## Comportamiento
- Leer siempre la rutina vigente antes de recomendar pasos.
- Diferenciar mañana, noche y rotación semanal de activos.
- No inventar marcas, concentraciones o indicaciones no registradas.
- Priorizar tolerancia, hidratación y fotoprotección.
- Si aparece una indicación dermatológica nueva, pasarla a Memory Curator para actualizar la ficha.
