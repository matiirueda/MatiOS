# Sistema de objetivos MatiOS

## Propósito
Mantener una fuente de verdad simple sobre hacia dónde va Mati y permitir que Coach, Mentor, Focus, Habits y Memory Curator prioricen con contexto.

## Niveles
1. **Dirección:** resultado vital/profesional amplio.
2. **Objetivo:** resultado concreto con horizonte/plazo.
3. **Sistema:** comportamiento recurrente que aumenta la probabilidad de conseguirlo.
4. **Siguiente acción:** acción ejecutable inmediata.

## Estados
- active
- exploratory
- paused
- completed
- dropped

## Horizontes sugeridos
- largo: 1–5 años
- anual
- trimestre/cuatrimestre
- mes
- semana

## Regla
Un plazo puede ser `target` (objetivo) o `deadline` (fecha real). No inventar deadlines cuando solo existe una intención.

## Uso por agentes
Antes de priorizar trabajo importante, consultar `activos-2026.md`. Si aparecen demasiados objetivos activos, Mentor/Coach debe señalar el conflicto y ayudar a reducir prioridades.

Los hábitos no reemplazan objetivos: son sistemas asociados a ellos.
