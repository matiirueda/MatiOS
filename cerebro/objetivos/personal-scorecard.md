# Personal Scorecard — MatiOS

Este documento define el tablero de crecimiento personal. Los valores concretos se actualizan en revisiones periódicas; no pretende ser una medición clínica ni una evaluación de valor personal.

## Escala

- **1–3:** área deteriorada o con fricción alta.
- **4–5:** funciona, pero limita otras áreas.
- **6–7:** base sólida con margen claro de mejora.
- **8–9:** fortaleza consistente.
- **10:** excepcional y sostenible; usar con moderación.

## Dimensiones

| Área | Qué se observa | Indicadores posibles |
|---|---|---|
| Dirección | Claridad de prioridades y rumbo | prioridades activas, decisiones cerradas, proyectos pausados |
| Carrera | Capital profesional y opcionalidad | skills, impacto, visibilidad, oportunidades |
| Emprendimiento | Creación de activos y mercado | clientes, MVPs, entregas, ventas, aprendizaje |
| Aprendizaje | Capacidad de adquirir y transferir conocimiento | horas profundas, proyectos, documentación, reconstrucción |
| Foco y ejecución | Capacidad de cerrar ciclos | tareas terminadas, WIP, bloqueos, sesiones profundas |
| Energía y recuperación | Base física para rendir | sueño, energía subjetiva, recuperación, estrés |
| Entrenamiento | Consistencia y progreso físico | sesiones, cargas, movilidad, rendimiento |
| Nutrición | Calidad y sostenibilidad alimentaria | adherencia, proteína, frutas/verduras, planificación |
| Relaciones | Calidad, reciprocidad y presencia | vínculos, citas, amigos, familia, límites |
| Finanzas | Seguridad y construcción patrimonial | ahorro, liquidez, deuda, activos, decisiones grandes |
| Hogar y entorno | Fricción o soporte del ambiente | orden, comodidad, diseño, mantenimiento |
| Diversión y experiencias | Vida fuera del rendimiento | juego, salidas, hobbies, experiencias nuevas |
| Sistemas personales | Cuánta carga mental absorbe MatiOS | automatizaciones, captura, backlog, documentación |
| Identidad y regulación | Coherencia entre valores y conducta | autoconcepto, tolerancia a frustración, estabilidad |

## Primera hipótesis de fortalezas

Basado en el historial operativo disponible, no en tests psicométricos:

| Fortaleza | Estimación inicial | Evidencia observable |
|---|---:|---|
| Curiosidad / aprendizaje | 9/10 | Explora dominios distintos y busca entenderlos construyendo. |
| Pensamiento sistémico | 9/10 | Tiende a convertir procesos en repos, flujos, agentes y arquitectura reusable. |
| Capacidad analítica | 8.5/10 | Trabaja con datos, software y problemas complejos y pide criterios explícitos. |
| Iniciativa | 8/10 | Suele convertir ideas en prototipos, compras, proyectos o experimentos reales. |
| Autoconciencia | 8/10 | Detecta y verbaliza patrones propios con bastante detalle. |
| Adaptabilidad | 8/10 | Cambia de herramientas y estrategias cuando ve una opción mejor. |
| Creatividad aplicada | 8/10 | Mezcla tecnología, diseño, negocio y vida cotidiana para construir soluciones. |
| Ambición | 8.5/10 | Mantiene objetivos profesionales, empresariales, físicos y personales simultáneos. |

## Primera hipótesis de riesgos

| Riesgo | Intensidad inicial | Qué vigilar |
|---|---:|---|
| Dispersión por exceso de intereses | Alta | demasiados proyectos abiertos y cambios de prioridad |
| Dependencia de novedad | Alta | caída de ejecución cuando desaparece la excitación inicial |
| Sobreoptimización | Media/Alta | agregar herramientas o métricas antes de consolidar lo básico |
| WIP excesivo | Alta | empezar más rápido de lo que se termina |
| Fricción ante tareas ambiguas | Alta | postergar cuando no existe una siguiente acción clara |
| Confundir planificar con avanzar | Media | arquitectura, investigación o prompts sin entrega usable |
| Carga física/cognitiva acumulada | Media | querer sostener trabajo, estudio, proyectos, deporte y vida social a máxima intensidad |

## Hipótesis central

La principal oportunidad no parece ser aumentar capacidad bruta, sino **convertir capacidad existente en progreso compuesto mediante foco, cierre de ciclos y sistemas que hagan sostenibles las tareas poco novedosas**.

En otras palabras:

> Menos proyectos simultáneos. Más cosas terminadas. Más aprendizaje convertido en activos.

## Regla de uso

El scorecard no debe transformarse en otra obligación. Actualizarlo solo cuando ayude a decidir.

Una revisión útil siempre termina con:

1. una fortaleza a explotar;
2. una restricción a trabajar;
3. una cosa a dejar de hacer;
4. una acción concreta para la próxima semana.
