# Biblioteca de rutinas

Las rutinas de esta carpeta son plantillas educativas. Para asignarlas se crea una versión individual con objetivo, días, ejercicios, volumen, esfuerzo, descansos, adaptaciones y fecha de revisión.

## Plantillas iniciales

- `full-body-3-dias-base.md`: cuerpo completo para tres días.
- `empuje-tiron-piernas-base.md`: división de empuje, tirón y piernas.
- `torso-pierna-4-dias-base.md`: frecuencia aproximada 2 con cuatro días.
- `especializacion-gluteos-frecuencia-3.md`: tres estímulos distintos de glúteos.

La explicación comparativa está en `../guias/tipos-de-rutina.md`.
